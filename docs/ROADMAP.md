Status of each phase from the project plan, checked against what is actually in the repository.

Status key: ✅ done · 🟡 partly done / code written but not verified · ⬜ not started

---

## What changed from the original plan

1. **Own data collection (Phase 5) moves earlier.** It now starts as soon as the sensor node works, alongside the CV work, instead of after it.
   - The main research question (CV-only vs IoT-only vs multimodal) needs synchronized image + sensor observations of the same plants over time.
   - Growing tomatoes and seeing disease develop takes weeks, so this phase is on the critical path for the whole project.
2. **Hardware matches what was ordered:** ESP32-S3 N16R8, a resistive soil-moisture probe and a Crowtail pH sensor. See `esp32/README.md`.
3. **The synthetic disease-risk model is labelled as a pipeline demo only (Phase 6).**
   - `ml/disease_risk/train.py` currently trains on data generated by hand-written rules.
   - A model trained this way just re-learns those rules, so its metrics cannot answer the research question and must not be reported as results.
